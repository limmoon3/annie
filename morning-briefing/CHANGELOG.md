# Changelog

## 2026-04-02

### Added
- 다중 수신자 지원 (`recipients.json` 기반, 수신자별 섹션 on/off)
- 카카오 친구 메시지 전송 (`friend` 방식, `kakao_uuid` 기반)
- 아기 성장 섹션 (월령, 발달사항, 돌 카운트다운 D-10/3/1/당일)
- 아기 발달 코퍼스 (`baby_corpus.json`, 0~12개월 종합 돌봄 데이터)
  - 월령별 발달사항, 이유식 단계/추천 메뉴/식재료, 추천 놀이
  - 예방접종 스케줄, 영유아 건강검진 시기, 수면 가이드
  - 매일 다른 놀이/이유식 메뉴 로테이션 표시
- 뉴스 헤드라인 (Google News RSS 한국 주요 뉴스 5건)
- 주간 날씨 요약 (월요일 한정, 5일 예보)
- 요일별 커스텀 알림 (수신자별 설정)
- 전송 이력 저장 (`send_history.json`)
- FastAPI 관리 웹 UI (대시보드, 수신자 CRUD, 미리보기, 수동 전송, 전송 이력)
- 수신자별 위치 기반 날씨/미세먼지 (위치별 API 캐시)
